# トレイリング注文 補助ツール（楽天証券 アルゴ注文対応）

楽天証券のアルゴ注文機能「**トレイリング注文**」の発注時に入力するパラメータを、簡単・即座に計算・確認できるWebアプリケーションです。

単一の HTML ファイル（`index.html`）のみで構成されており、サーバーのセットアップ不要でブラウザで直接開いてご利用いただけます。

---

## 🌟 主な特徴

### 1. 東証の呼値単位（Tick Size）自動補正機能
- 注文不可能な不適合株価（例: 20,000円超での20,001円など）の発生を防ぐため、試算数値を東証の呼値単位へ自動四捨五入補正します。
- **「一般銘柄 (標準呼値)」**（3,000円以下: 1円 / 5,000円以下: 5円 / 30,000円以下: 10円...）および **「TOPIX500 構成銘柄 (小数呼値)」** を瞬時に切り替え可能です。

### 2. カード選択フォーカス機能（転記ミス防止）
- 10個あるカードのうち、転記・発注したいカードをクリックすると、**選択したカードのみがゴールドで強調ハイライト** され、その他のカードが20%に減光されます。
- 入力中の視覚的混乱を完全に排除し、楽天証券画面への転記ミスを防止します。

### 3. スッキリとした高視認性デザイン
- 楽天証券注文画面に入力する3大数値（🔴成行売り損切 🟢トレイリング開始 🔵下落幅設定）を特大太字（`text-2xl font-black`）かつ **右寄せ表示**。

### 4. 日本株の単元株（100株単位）に対応
- 保有数量の入力は **100株単位 (`step="100" min="100"`)** で制御され、実取引に即したスムーズな数値入力が可能です。

---

## 🚀 使い方

1. リポジトリ内の [`index.html`](./index.html) をお使いのWebブラウザで開きます。
2. **「購入株価 (取得単価)」** を入力します。
3. 必要に応じて **「東証呼値区分」**（一般銘柄 / TOPIX500）や **「保有数量」** を指定します。
4. 試算カード一覧から、転記したい変動率カードを**クリックして集中選択**し、楽天証券の注文画面へ転記します。
