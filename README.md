# トレイリング注文 補助ツール（楽天証券 アルゴ注文対応）

楽天証券のアルゴ注文機能「**トレイリング注文**」の発注時に入力するパラメータを、簡単・即座に計算・確認できるWebアプリケーションです。

単一の HTML ファイル（`index.html`）のみで構成されており、サーバーのセットアップ不要でブラウザで直接開いてご利用いただけます。

---

## 🌟 主な特徴

### 1. 楽天証券 注文画面への転記用数値を最優先で強調表示
各変動率レベル（±1% 〜 ±10%）において、楽天証券のトレイリング注文画面に入力する **3大パラメータ** を高コントラストバナーおよびカラー指定でハイライト表示します。

- 🔴 **1. 成行売り株価 (円)**: 損切り発動株価（例: 1%レベルなら `-1.0%` 下落の **990円**）
- 🟢 **2. 開始条件株価 (円)**: トレイリング追従スタート株価（例: 1%レベルなら `+1.0%` 上昇の **1,010円**）
- 🔵 **3. 下落幅設定 (%)**: 高値からの反落幅設定（例: **0.2%** / -2円幅）および利確確定時の約定株価（1,008円）・確定利益（+800円）

### 2. 日本株の単元株（100株単位）に対応
- 保有数量の入力は **100株単位 (`step="100" min="100"`)** で制御され、実取引に即したスムーズな数値入力が可能です。
- 保有数量未入力の場合は、単価・利回りパーセント比較としてご利用いただけます。

### 3. トレイリング削り幅（デフォルト20%）の柔軟な変更
- ピーク上昇幅から何％削れた時点で売却するか（デフォルト: 上昇率の20%削り、例: +1.0%上昇時に -0.2%削りで +0.8%確定）を自由に変更できます。

### 4. 洗練されたUI・レイアウト
- Tailwind CSS CDN および Lucide Icons によるモダンなダークモード金融UI
- 入力フォームおよび操作ボタンのピクセルパーフェクトな水平整列デザイン

---

## 🚀 使い方

1. リポジトリ内の [`index.html`](./index.html) をお使いのWebブラウザで開きます。
2. **「購入株価 (取得単価)」** を入力します。
3. 必要に応じて **「保有数量」** や **「トレイリング削り幅」** を指定します（クイック入力ボタンも利用可能）。
4. 表示された ±1% 〜 ±10% のカードから、設定したいレベルの数値を楽天証券の注文画面へ転記します。
